Photographs shown on case pages.

Written by scripts/media-fetch.js during the pulse, committed by the same `git add data` the
pulse workflow already runs, and copied into public/media/ by the build. They are here rather
than in public/ because public/ is gitignored and rebuilt from nothing on every CI run.

Everything here is public domain or Creative Commons, verified against the Wikimedia Commons
API at the moment of download. Attribution and licence for each file live in the owning
case.json, not in the filename.
