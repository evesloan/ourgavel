## The blocker you need to know about

`node scripts/verdict.live-check.js` currently **exits non-zero on a clean tree** (confirmed by
stashing this change — the failure is pre-existing, not caused by this work). Cause: the Fernandez
ticker already carries a GUILTY-classified headline ("...after Mario Fernandez convicted of
murder"), but the verdict engine reads only **1 of 3** independent newsroom families in-ticker so
far, so it correctly holds — and the live-check flags "1 item needs a human eye."

Because `apply.js`'s gate runs `verdict.live-check.js`, **the pulse applier is currently refusing
every handoff (all lanes) and will keep doing so until the Fernandez verdict publishes** (which sets
`case.json.verdict`, turning the live-check green). This is self-healing: once 2 more independent
families' "convicted" headlines land in the Fernandez ticker, the engine publishes and the queue
unblocks. Until then, POSTing a handoff burns it (failed issues are never retried), so this run did
**not** POST — the handoff is provided as an applyable doc instead.
