# DEV run log — 2026-08-29 ~20:32 UTC

## Shipped: split/partial-verdict guard in the verdict engine (before Monday's Clancy verdict)

**The gap, found by testing before it could fire.** Clancy's jury (resumes Mon Aug 31) has FIVE
options — first-degree murder, second-degree murder, manslaughter, not guilty, NGRI. Outlets routinely
write a partial verdict as one headline: *"found not guilty of first-degree murder, guilty of
manslaughter."* `classify()` tests NOT_GUILTY before GUILTY, so it read the acquittal phrase and
returned **NOT_GUILTY**. Probed the live engine against realistic verdict-day phrasings:

| headline | old classify() |
|---|---|
| "found not guilty of first-degree murder, guilty of manslaughter" | **NOT_GUILTY** ✗ |
| "acquitted of first-degree murder but convicted of manslaughter" | **NOT_GUILTY** ✗ |
| "not guilty of murder, guilty on lesser charge" | **NOT_GUILTY** ✗ |

Three newsrooms phrasing a real manslaughter conviction that way → 3 NOT_GUILTY tags → consensus →
the engine would have **published a FALSE ACQUITTAL for a woman convicted of killing her children**,
with nobody watching. This was the site's single highest-severity latent failure, two days from its
biggest moment.

**The fix — purely subtractive, cannot cause a publication.** A single headline asserting BOTH an
acquittal signal and a conviction signal is ambiguous about the *overall* outcome by construction, so
it now classifies as `null`: the engine holds and a human writes the split-verdict aftermath
(AGENT.md — exactly the case a machine must not decide). The guard can only turn a would-be single
tag into `null`; it never invents a positive, so structurally it can only ever cause a HOLD, never a
mispublish.

- `ACQUITTAL_SIGNAL` = `not guilty` | `acquit(ted|tal|s)` | `cleared of` | `not criminally responsible`
- `CONVICTION_SIGNAL` = `convict(s|ed|ion)` | a `guilty` **not** preceded by `not`
- split = both present → `isSplitVerdict()` → `classify()` returns null at the top, before OUTCOMES.

**Proven no regression.** Added Gate 1c (6 split headlines must hold) + a clean-verdict counter-set
