## What shipped
A new top-level page `/embed/`, plus its wiring, delivered as an **idempotent patch script**
(`scripts/patch-embed-landing.js`, run once by the applier) rather than a full-file `build.js`
replacement — build.js is the most contended file, so the patch composes onto whatever is on
origin at apply time. Sentinel-guarded (`EMBED_LANDING_V1`); re-running is a no-op; a moved anchor
throws and the applier reverts (no silent bad build).

Three insertions:
1. **The landing itself** — `files['embed/index.html'] = embedLanding`. Sections: what it is, what
   readers get, a **live example** (the featured case's central question + 3 real sourced cards,
   generated at build time from `board.json` so it can never drift), a **copy-paste iframe snippet
   per active case** (6 snippets, in read-only textareas), and an **FAQ** (5 Q&A) marked up as
   `FAQPage` schema. Every FAQ question and answer is generated from one array that feeds both the
   visible cards and the JSON-LD, so the markup-truth rule holds (`seo.test.js` checks each against
   the rendered text: +26 assertions, all green).
2. **Sitemap** — `/embed/` added, `weekly` / `0.5`, **no lastmod** (no dated content → no fake date).
3. **Internal link** — every full board page now links to `/embed/` from the embedbox panel
   ("New to this? How embedding works, and boards for every case →"). The embed variant is
   unaffected (embedbox renders on the full board only).
